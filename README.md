# Game-Dev

Welcome to my game development repository! While my [`Projects`](https://github.com/Slim2Dev/Projects) repository covers algorithms, console apps, and general programming practice, this space is dedicated exclusively to **video game development**—from 2D prototypes and mechanics experiments to full playable projects.

Each folder houses a separate game project with its own assets, source code, and documentation.

## Projects

| Project | Description | Focus Areas |
| :--- | :--- | :--- |
| **[`2dgame`](./2dgame)** | A 2D game project exploring core gameplay systems and visual presentation. | 2D mechanics, movement/controls, game loop, sprite/asset integration |

## Goals & Learning Focus

* **Game Mechanics & Systems:** Designing responsive player controls, collision detection, physics, and state management.
* **2D & 3D Development:** Experimenting with rendering, animations, UI, and game architecture across different styles and tools.
* **Complete Game Loops:** Moving from rough prototypes to polished, playable builds.
